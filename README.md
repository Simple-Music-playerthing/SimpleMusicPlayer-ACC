# Simple Music Player Window
A simple mp3 software with pre-made playlist integrated for demonstration purpose.\
The window is available as desktop application and webpage.
<h4>User interface:</h4>
<img src="/public/demo.png" width="250" height="450">

# Key features
- loop button
- shuffle button
- basic interface control
- visual carousel 

# How to access the window
<h3> Ngrok web access </h3>
Accessable on the main branch.

Use `npm run install` `npm run dev` to complete setup and view.
<h3> Electron desktop application </h3> 
Accessable on the electroin branch. Can be downloaded as exe file. Futher instruction follow readme in electron branch.
